# 表情包目录

把表情图片放在本目录下即可，不用改代码、不用重启。

## 命名规则

- **文件名去掉扩展名就是表情名**，也就是 AI 能选择的名称。
- 支持中文或英文，大小写不敏感，例如 `开心.png`、`无语.gif`、`doge.jpg`。
- 支持格式：`png / jpg / jpeg / gif / webp`，单个文件建议不超过 5MB。
- 名称不要包含空格、斜杠、路径分隔符；同一个名字（仅大小写不同）只会保留一个。
- 修改本目录内容后，系统会自动重新扫描，无需重启。

## 内置建议清单

| 文件名 | 含义/使用场景 |
| --- | --- |
| 开心.png | 高兴、打招呼、被夸 |
| 无语.png | 离谱、不知道怎么接话 |
| 委屈.png | 被欺负、撒娇求安慰 |
| 得意.png | 炫耀、计划得逞 |
| 生气.png | 假装生气、抗议 |
| 疑惑.png | 没听懂、问号脸 |
| 赞.png | 赞同、夸奖 |
| 笑哭.png | 太好笑 |
| 害怕.png | 惊恐、认怂 |
| 摸鱼.png | 偷懒、不想干活 |
| 晚安.png | 结束聊天、睡觉 |
| 拒绝.png | 婉拒、不想做 |

把对应图片按上面的名字放进本目录后，AI 就能在回复里通过 `emoji` 字段选择它们。

## 说明

- AI 只能看到表情名称列表，不能指定文件路径。
- 一次回复最多发送 1 个表情；未知名称会被忽略。
- 本文件只是说明清单，不会被当作表情加载。
